03 / COMPATIBILITY MATRIX

Drone, giao thức và đầu ra

Khả năng theo loại dữ liệu xuất từ thiết bị — không phải cam kết mọi firmware đều tương thích.

Lưu ý: một dòng drone có thể xuất nhiều biến thể tệp theo ứng dụng, firmware, cảm biến. Phải kiểm tra nội dung tệp trước khi chuyển đổi.

05 / OPEN SOURCE REFERENCES

Hệ sinh thái tham khảo

Kiến trúc tham khảo; mã nguồn giao diện và bộ parser trong gói này được viết riêng.

BRIDGE / GATEWAYOpen UAV Telemetry Bridge ↗

MAVLink / DJI → MQTT, WS, HTTP (ý tưởng cho adapter sau này)

SCHEMA / CANONICALNDIEM ↗

Mô hình dữ liệu liên thông drone dị thể; XML ở bản này là schema riêng

DETECTION / TAKDragonSync ↗

Drone detection / Remote ID → CoT và MQTT, khác telemetry bay nội bộ

DJI / SRTDJI Metadata Embedder ↗

SRT → CSV, GPX, KML, GeoJSON, CoT ở CLI tham khảo

ULOG / PARQUETPX4 Flight Review Rust ↗

Converter ULog → Parquet; bản tham khảo có workflow server riêng

PHOTOGRAMMETRYOpenDroneMap ↗

Pipeline tạo point cloud, DEM, orthophoto từ ảnh UAV
